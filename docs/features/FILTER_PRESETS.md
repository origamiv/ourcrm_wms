# Конструктор фильтров

Табличные экраны используют общий конструктор на базе SVAR Vue Filter. Поля и допустимые значения задаются реестром конкретного экрана; произвольные имена полей не передаются в SQL. Быстрые фильтры экрана, активные сохранённые наборы и временный набор объединяются через `AND`. Внутри набора поддерживаются вложенные группы `AND` и `OR`.

Персональные наборы хранятся в `main.user_filter_presets` с обязательными `tenant_id` и `user_id`. Пользователь видит и изменяет только свои наборы текущей организации. Активность плитки хранится на сервере и восстанавливается после повторного входа.

Web API с сессионной авторизацией:

- `GET /web/filter_presets?screen_key=...` — список наборов экрана;
- `POST /web/filter_presets` — создание;
- `PUT /web/filter_presets/{id}` — изменение правил, имени или активности;
- `DELETE /web/filter_presets/{id}` — мягкое удаление.

Имя ограничено 80 символами, экран — 30 наборами, дерево — 50 условиями и пятью уровнями. Серверно-пагинируемые журналы принимают сериализованное дерево в параметре `filter` размером до 32 КБ и применяют его до пагинации и календарной агрегации.
