# Общий поиск по таблицам

На экранах со стандартным конструктором фильтров используется общий компонент поиска. Поиск начинается после трёх символов с задержкой 300 мс и выполняется по выбранным пользователем полям.

В режиме фильтрации поиск объединяется с быстрыми и сохранёнными фильтрами через `AND`. Значения нескольких поисковых полей объединяются через `OR`. Серверные списки принимают параметры `search`, `search_fields[]`, `search_mode` и `search_index`; каждый endpoint проверяет поля по собственному разрешённому списку.

В режиме подсветки состав данных и экспорт не меняются. Найденные строки подсвечиваются, а текущая строка выделяется отдельно. Переход выполняется стрелками в компоненте поиска или клавишами `Enter` и `Shift+Enter`.

Выбранные поля сохраняются в `localStorage` с разделением по пользователю, организации и экрану. Строка и режим поиска не сохраняются.
