# Фоновые процессы

Раздел **Обслуживание → Фоновые процессы** показывает агрегированную активность активных вебхуков организации. Экран и внутренний web API доступны администраторам через сессию и CSRF-защиту.

## Источники и группировка

Итог строится по неудалённым `integration.webhooks` со статусом `1`. История берётся из `wms.import_runs` по `source_webhook_id` и `tenant_id`; поля `cnt` и `dat_last_run` не заменяют журнал запусков.

Переключатель **Клиенты / Вебхуки** меняет состав общей агрегации, но не фильтрует отдельную запись. В обоих режимах API возвращает одну итоговую строку. В клиентском режиме учитываются только вебхуки, связанные с доступными неудалёнными клиентами со статусом `1`; вебхуки без `client_id` исключаются. «Без запуска» — количество вошедших в итог вебхуков, у которых нет запусков в выбранном периоде.

Верхние показатели классифицируют уникальных клиентов или вебхуки по последнему запуску выбранного периода. Для клиента выбирается самый поздний запуск среди всех его вебхуков. Статусы распределяются так:

- `completed` — успешные;
- `failed` — «Есть успешные», если ранее в периоде был `completed`, иначе неуспешные;
- `queued` и `running` — выполняются;
- при отсутствии запусков сущность попадает в «Без запуска».

Общее число запусков у календаря включает все четыре статуса и не является числом уникальных сущностей.

## Периоды и API

`GET /web/background_processes` принимает `group_by=clients|webhooks`, `period=today|yesterday|week|month|hours_4|hour|minutes_15` и необязательный `marketplace=all|wildberries|ozon|yandex_market|none`. Значение `none` выбирает вебхуки без маркетплейса. Ответ содержит одну итоговую строку с показателями и разреженными интервалами активности строго за выбранный период. Пагинация не используется.

`GET /web/background_processes/runs` с теми же `group_by`, `period` и `marketplace`, а также `bucket_start` возвращает запуски выбранного квадрата календаря. Ответ содержит ID запуска, ID клиента или вебхука в зависимости от режима, дату и время, статус и число обработанных записей; страницы содержат до 100 строк.

Календарные границы и подписи рассчитываются в `Europe/Moscow`: неделя начинается в понедельник. Месяц разбивается по дням, неделя — по часам, сегодня и вчера — по 15 минут, короткие интервалы — по минутам. Квадраты переносятся на новые строки по ширине блока без горизонтальной прокрутки.

Цвет квадрата определяется составом завершённых запусков интервала: только успешные — зелёный с интенсивностью по числу запусков, успешные вместе с ошибками — жёлтый, только ошибки — красный. Интервалы без окончательного результата остаются нейтральными.
