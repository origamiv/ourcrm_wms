# Фоновые процессы

Раздел **Обслуживание → Фоновые процессы** показывает агрегированную активность активных вебхуков организации. Экран и внутренний web API доступны администраторам через сессию и CSRF-защиту.

## Источники и группировка

Итог строится по неудалённым `integration.webhooks` со статусом `1`. История берётся из `wms.import_runs` по `source_webhook_id` и `tenant_id`; поля `cnt` и `dat_last_run` не заменяют журнал запусков.

Переключатель **Клиенты / Вебхуки** меняет состав общей агрегации, но не фильтрует отдельную запись. В обоих режимах API возвращает одну итоговую строку. В клиентском режиме учитываются только вебхуки, связанные с доступными неудалёнными клиентами со статусом `1`; вебхуки без `client_id` исключаются. «Без запуска» — количество вошедших в итог вебхуков, у которых нет запусков в выбранном периоде.

Статусы запусков распределяются так:

- `completed` — успешные;
- `failed` — неуспешные;
- `queued` и `running` — выполняются;
- общее число включает все четыре статуса.

## Периоды и API

`GET /web/background_processes` принимает `group_by=clients|webhooks` и `period=today|yesterday|week|month|hours_4|hour|minutes_15`. Ответ содержит одну итоговую строку с показателями выбранного периода и разреженные интервалы активности за три последовательных периода. Пагинация не используется.

Календарные границы и подписи рассчитываются в `Europe/Moscow`: неделя начинается в понедельник. Месяц и неделя разбиваются по дням, сегодня и вчера — по часам, короткие интервалы — по минутам.
