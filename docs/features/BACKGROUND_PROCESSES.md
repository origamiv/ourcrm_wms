# Фоновые процессы

Раздел **Обслуживание → Фоновые процессы** показывает агрегированную активность активных вебхуков организации. Экран и внутренний web API доступны администраторам через сессию и CSRF-защиту.

## Источники и группировка

Строки строятся по неудалённым `integration.webhooks` со статусом `1` или временным статусом выполнения `3`. История берётся из `wms.import_runs` по `source_webhook_id` и `tenant_id`; поля `cnt` и `dat_last_run` не заменяют журнал запусков.

Доступны группировки по клиентам и вебхукам. В клиентской группировке вебхуки без `client_id` не показываются. «Без запусков» — количество вебхуков строки, у которых нет запусков в выбранном периоде; для строки вебхука это `0` или `1`.

Статусы запусков распределяются так:

- `completed` — успешные;
- `failed` — неуспешные;
- `queued` и `running` — выполняются;
- общее число включает все четыре статуса.

## Периоды и API

`GET /web/background_processes` принимает `group_by=clients|webhooks`, `period=today|yesterday|week|month|hours_4|hour|minutes_15` и `page`. Ответ содержит показатели выбранного периода, пагинацию по 50 строк и разреженные интервалы активности за три последовательных периода.

Календарные границы и подписи рассчитываются в `Europe/Moscow`: неделя начинается в понедельник. Месяц и неделя разбиваются по дням, сегодня и вчера — по часам, короткие интервалы — по минутам.
