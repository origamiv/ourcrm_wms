# Каталог WB и OZON

Команда `integration:sync-catalog` загружает каталог выбранного webhook WB или OZON и передаёт данные через последовательность `integration.rules`.

Результаты сохраняются в `wms.goods_marketplace`. Сопоставление выполняется по артикулу/offer ID и штрихкоду. Существующее ручное сопоставление не изменяется.

Автоматическое создание мастер-товаров выключено по умолчанию. Для включения для организации используется:

```bash
php artisan tenant:feature TENANT_ID integration.auto_create_marketplace_goods 1
```

Для отключения используется значение `0`. При включённой фиче создаются минимальные карточка и товар WMS без категории.
