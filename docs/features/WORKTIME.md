# Рабочий график

`main.worktime` хранит неизменяемый журнал событий пользователей: `start`, `pause_start`, `pause_end`, `finish`. Время события записывается в `timestamptz`, дата рабочего дня — в ISO-формате.

Кнопки в шапке доступны каждому активному пользователю. Администратор видит в `/main/worktime` сотрудников своей организации, обычный пользователь — только свою строку. Отчёт строится по диапазону дат с календарём Пн–Вс; значения дат в интерфейсе отображаются в формате `дд.мм.гг`.

Web-маршруты: `GET /web/worktime/state`, `GET /web/worktime`, `POST /web/worktime/{start|pause|finish}`. Те же операции доступны через Bearer API без префикса `/web`.
