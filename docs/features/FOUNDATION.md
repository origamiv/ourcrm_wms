# Состояние основы WMS

## Реализовано

- Правила проекта, стандартные каталоги Laravel без нового кода в `Modules`.
- Inertia 2 + Vue 3 + TypeScript; Livewire 3 для входа. Визуальная основа уточнена по Figma, шрифт Manrope.
- Вход и выход, экран пользователей с записью в общую `public.users`, существующие роли из `main`, изоляция по `tenant_id`.
- IndexedDB, согласованный снимок и загрузка изменений, общий полиморфный журнал PostgreSQL `public.entity_changes` с классом модели и ID записи, отдельные счётчики тенантов в `public.sync_state`, обработка SQL-изменений других приложений.
- Публичное API общих сервисов и Scramble. Swagger удалён из зависимостей, конфигурации и шаблонов; старый маршрут выдачи токена по ID отключён. Локальный пользовательский файл прежней спецификации сохранён на диске, но исключён из Git и не опубликован маршрутами.
- Добавлены минимальные базовые классы для запросов, контроллеров и моделей, стандартные stubs переключены на них. Пользователь наследует Laravel Authenticatable и использует SoftDeletes, поскольку служит моделью авторизации.

Подробности: [пользователи и синхронизация](USERS.md), [API](API.md), [руководство](../help/INDEX.md).

## Следующие этапы

- Полностью очистить неиспользуемую предметную область прежней системы и перенести полезные классы из существующего `Modules`. Старые web-маршруты и автоматическая регистрация route attributes уже отключены для нового интерфейса; унаследованные исходники пока остаются.
- Адаптировать специализированный генератор сущностей и все его шаблоны под схемы и раздельные запросы создания/обновления. Новые складские сущности и конкретные схемы реализуются по отдельным задачам.
- Подключить ClickHouse для истории и статистики. Оперативный журнал синхронизации сущностей работает в PostgreSQL и не заменяет аналитическое хранилище.
- Определить срок хранения журнала и протокол сброса старых курсоров перед внедрением очистки. Холодный офлайн-запуск, очередь офлайн-изменений и управление ролями не входят в текущий каркас.

Общий механизм и подключение новых сущностей: [SYNC.md](SYNC.md).
