# Инструкции

Инструкции хранятся в `wms.instructions` и привязаны к разделу
левого меню. Пользователь открывает список кнопкой «Инструкции» в верхней
панели; отображаются только активные инструкции текущего раздела.

Поддерживаются PDF, Markdown, HTML и MP4. Просмотр и скачивание выполняются
через авторизованные маршруты, прямой путь к файлу в Storage не публикуется.
Администратор управляет записями через «Администрирование → Инструкции».

Системный комплект подробных Markdown-инструкций находится в
`docs/help/instructions` и устанавливается командой
`php artisan instructions:install`. Такие записи имеют `tenant_id = NULL` и
доступны всем организациям. Команда идемпотентна: повторный запуск обновляет
файлы и существующие записи по `shortname`, не создавая дубликаты.

Разделы помощи доступны по адресам `/main/help`, `/clients/help`,
`/goods/help`, `/integration/help`, `/fulfillment/help`,
`/maintenance/help` и `/logistics/help`. Markdown отображается безопасным HTML-рендерером,
включая локальные обезличенные скриншоты из `public/help-assets`.
