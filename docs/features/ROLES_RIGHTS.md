# Матрица ролей и прав

Страница `/main/roles_rights` доступна через пункт «Роли и права» верхней ленты администрирования. Компоновка основана на [Figma 5667:664](https://www.figma.com/design/x2UByywVb3CQd8dbC9MKEi/?node-id=5667-664): роли в столбцах, права строками в раскрываемых группах, флажки назначений. Группы формируются по `main.permissions.resource`, названия строк и столбцов берутся из реальных записей. Поиск раскрывает найденные права. Кнопка «Добавить роль» открывает существующую форму создания роли.

Источники: `main.roles`, `main.permissions`, `main.permission_role`. Отображаются активные неудалённые роли и права своей организации. Флажок установлен, если существует активная неудалённая строка назначения этой пары в том же tenant_id. Доступ к странице и изменениям требует активного администратора. Назначения меняют общую таблицу, используемую приложениями; WMS пока продолжает проверять роль admin для своих административных экранов, матрица не заменяет эти проверки.

## Сохранение

`PUT /web/roles/{roleId}/permissions/{permissionId}` — web-сессия; `PUT /api/roles/{roleId}/permissions/{permissionId}` — Sanctum Bearer. Тело: `enabled` (boolean), `version` (строка). Версия пары — максимальная версия её строк назначения, включая мягко удалённые; при отсутствии строк — `"0"`. Организация определяется сервером.

Сохранение проверяет организацию, статус и удаление обеих связанных сущностей. Строка счётчика тенанта блокируется на время проверки версии и изменения. При включении используется существующая строка либо создаётся новая; лишние дубликаты отключаются. При выключении все строки пары получают status=0 и deleted_at. Повторное включение восстанавливает существующую строку.

Ответ 200: `data` — список канонических строк назначения с версиями, `enabled`, `version`. Конфликт возвращает 409 и `current`; браузер загружает изменения, повторная запись возможна только действием пользователя. Чужие, неактивные или удалённые роли/права дают 404, отсутствие прав — 403, неверные поля — 422.

Флажок меняется после успешного ответа сервера, затем обновляются IndexedDB и другие вкладки. Пока идёт сохранение или первичная загрузка, переключение недоступно. Без сети разрешён просмотр уже загруженной матрицы.

## Синхронизация

В реестре добавлен `permission_roles` с классом `App\Models\PermissionRole`. Он использует общие `/web/sync/permission_roles` и `/api/sync/permission_roles`. Роли, права и назначения имеют отдельные курсоры и кэши. Миграция `000006` создаёт начальный журнал назначений и триггеры INSERT/UPDATE/DELETE/TRUNCATE, не меняя исходные назначения. Откат удаляет только эти триггеры и события модели, инвалидируя курсоры затронутых организаций.
