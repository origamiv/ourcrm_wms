# Статусы заказов

Справочник **Логистика → Справочники → Статусы заказов** содержит этапы обработки заказа. В карточке укажите название, краткое имя, внешний код и статус записи.

Перед добавлением найдите похожее значение, чтобы не создавать дубликат. Отключайте статус, если он больше не должен выбираться в новых заказах. Используемый статус не удаляйте — сначала переведите связанные заказы на другое допустимое значение.
