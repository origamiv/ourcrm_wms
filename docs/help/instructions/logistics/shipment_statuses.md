# Статусы отправлений

Справочник **Логистика → Справочники → Статусы отправлений** содержит этапы обработки отгрузки: создание, проверку, передачу в доставку и завершение.

Сохраняйте единое написание названий и внешних кодов. Не удаляйте используемый статус; если он больше не нужен, отключите его и настройте новый статус в интеграции или рабочем процессе.
