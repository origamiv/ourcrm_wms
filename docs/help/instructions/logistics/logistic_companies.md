# Логистические компании

Справочник **Логистика → Справочники → Логистические компании** содержит организации, участвующие в перевозке и доставке заказов.

Перед созданием найдите компанию по названию и внешнему коду. Заполните уникальные название и краткое имя, при необходимости укажите внешний код, затем сохраните запись. Перед отключением проверьте активные службы доставки и связанные заказы.
