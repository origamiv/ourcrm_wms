# Источники заказов

Справочник **Логистика → Справочники → Источники заказов** описывает, откуда поступил заказ: сайт, маркетплейс, оператор или другой канал.

Используйте понятные названия и уникальные краткие имена. Внешний код должен совпадать с кодом источника во внешней системе. Перед отключением проверьте заказы, которые уже используют этот источник.
