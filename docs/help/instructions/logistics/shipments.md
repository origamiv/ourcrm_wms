# Отгрузки

Раздел **Логистика → Отгрузки** показывает операции отправки заказов. Для каждой записи доступны идентификатор **#**, внешний код, заказ, клиент, склад, статус, даты создания, проверки и отправки.

## Проверка отгрузки

1. Найдите отгрузку по внешнему коду или связанному заказу.
2. Проверьте клиента, склад и соответствие заказа.
3. Уточните статус отправления и даты обработки.
4. После изменения сохраните запись и дождитесь подтверждения сервера.

Отгрузка может ссылаться на заказ, поэтому перед изменением или удалением проверьте текущий статус заказа и связанные операции. Статусы отправлений ведутся в справочнике **Статусы отправлений**.
