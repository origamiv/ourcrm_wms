# Статусы отмены заказов

Справочник **Логистика → Справочники → Статусы отмены заказов** хранит причины и состояния отмены. Название и внешний код должны однозначно описывать значение, а краткое имя — соответствовать правилам WMS.

Изменяйте запись только после проверки связанных заказов и интеграций. Если статус больше не применяется, отключите его вместо удаления.
