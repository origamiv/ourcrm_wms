# Задачи

В **Фулфилмент → Задачи** найдите задачу по статусу, типу или складу. Откройте карточку, ознакомьтесь с товарами и историей, выполните этап и сохраните результат. Перемещение карточки на доске меняет статус после подтверждения.

![Экран раздела Фулфилмент](/help-assets/fulfillment.png)

Пример: приемка создаёт задачу размещения; оператор открывает список товаров и последовательно подтверждает ячейки.

## Для чего нужен этот раздел
Фулфилмент описывает движение товара: склад, ячейку, приемку, размещение, задачу и доставку. Справочники задают допустимые значения операций.
## Важные данные
Проверяйте **склад**, **ячейку**, товар, количество, статус и идентификатор операции. Остаток размещения должен соответствовать фактически принятому количеству.
## Пошаговая проверка
1. Подготовьте справочники.
2. Проверьте доступный склад и ячейку.
3. Выполните операцию по шагам.
4. Проверьте итоговый статус и остаток.
