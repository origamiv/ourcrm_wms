# Склады

![Экран раздела Фулфилмент](/help-assets/fulfillment.png)

Откройте **Фулфилмент → Склады**, нажмите добавление, укажите название, тип и адрес, затем сохраните. Через действия строки откройте просмотр или редактирование.

Пример: создайте склад «Основной», затем добавьте его ячейки и зоны.
