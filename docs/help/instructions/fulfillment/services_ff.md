# Услуги фулфилмента

![Экран раздела Фулфилмент](/help-assets/fulfillment.png)

Откройте справочник услуг, выберите тип, укажите название, стоимость и статус. Для услуги доставки дополнительно задайте маркетплейс и настройки заказа.

Пример: услуга «Хранение» относится к типу хранения и используется в тарифе клиента.
