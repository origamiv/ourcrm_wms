# Приемки

![Экран раздела Фулфилмент](/help-assets/fulfillment.png)

Откройте **Фулфилмент → Приемки**, создайте приемку, выберите склад, клиента и дату, добавьте товары и количества. По мере обработки обновляйте статус и контролируйте прогресс.

Пример: после фактического пересчёта сохраните принятое количество и перейдите к задаче размещения.
