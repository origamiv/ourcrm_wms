# Каталоги маркетплейсов

В **Фулфилмент → Каталоги МП** выберите фильтры интеграции, маркетплейса и сопоставления. Проверяйте внешний SKU и ссылку на мастер-каталог WMS. Статус «Ожидает» означает, что сопоставление не завершено.

![Экран раздела Фулфилмент](/help-assets/fulfillment.png)

Пример: после включения автосоздания новая позиция получает «Создан», а при повторной синхронизации — «Автоматически».

Синхронизация выполняется в очереди: несколько аккаунтов загружаются параллельно, каталог каждого аккаунта — страницами. Ход загрузки смотрите в **Обслуживание → Импорты**. Статус «В очереди» между страницами нормален; при временном сетевом сбое текущая страница повторяется автоматически. Повторный запуск активного аккаунта не создаёт второй импорт. Если импорт завершился ошибкой реквизитов, исправьте их в аккаунте и запустите синхронизацию снова.

Чтобы привязать или перепривязать мастер-товар, нажмите карандаш в колонке «Мастер-каталог WMS». Введите код или наименование, выберите товар в списке и нажмите «Сохранить». Категории отображаются для поиска, но выбрать их нельзя.

## Для чего нужен этот раздел
Фулфилмент описывает движение товара: склад, ячейку, приемку, размещение, задачу и доставку. Справочники задают допустимые значения операций.
## Важные данные
Проверяйте **склад**, **ячейку**, товар, количество, статус и идентификатор операции. Остаток размещения должен соответствовать фактически принятому количеству.
## Пошаговая проверка
1. Подготовьте справочники.
2. Проверьте доступный склад и ячейку.
3. Выполните операцию по шагам.
4. Проверьте итоговый статус и остаток.
