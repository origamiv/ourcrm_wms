# Справочники фулфилмента

![Экран раздела Фулфилмент](/help-assets/fulfillment.png)

Откройте **Фулфилмент → Справочники** и выберите тип склада, вид склада, тип хранения, зоны, типы и статусы задач, приоритеты, маркетплейсы или службы доставки. Настройте справочники до создания рабочих документов.
