# Маркировка товаров

![Экран раздела Товары](/help-assets/goods.png)

В **Товары → Маркировка** добавьте код, выберите клиента, товар и вид кода, укажите даты и сохраните. Поиск выполняется по коду, просмотр и изменение доступны в действиях строки.

Пример: для «Честного знака» сохраните полный код без удаления ведущих нулей.
