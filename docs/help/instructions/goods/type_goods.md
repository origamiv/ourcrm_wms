# Типы товаров

![Экран раздела Товары](/help-assets/goods.png)

Откройте **Справочники → Типы товаров**, нажмите добавление, заполните название, краткое имя и статус. Сохранённый тип появляется в выборе карточки товара.

Пример: создайте тип «Штучный товар» для обычных единиц и тип «Комплект» для наборов.
