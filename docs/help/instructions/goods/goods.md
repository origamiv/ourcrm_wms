# Товары

![Экран раздела Товары](/help-assets/goods.png)

Откройте **Товары → Товары**, найдите запись по названию, коду или артикулу. Для создания заполните карточку, укажите тип, единицу измерения, штрихкоды и родителя, затем сохраните.

Пример: товар без детей может быть обычным товаром или ручной категорией; если у него появились дети, категория вычисляется автоматически.
