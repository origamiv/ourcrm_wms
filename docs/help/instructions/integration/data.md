# Данные интеграций

![Экран раздела Интеграции](/help-assets/integration.png)

В **Интеграции → Данные** создайте описание набора данных: выберите вебхук и сервис, укажите структуру JSON и сохраните. Проверяйте формат примера до публикации.

Пример: входное поле `offer_id` сопоставьте с внешним SKU, а `name` — с названием товара.
