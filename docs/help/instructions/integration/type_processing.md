# Типы обработки

![Экран раздела Интеграции](/help-assets/integration.png)

В **Справочники → Типы обработки** добавьте название операции и короткое имя. Используйте тип в правиле, проверьте обязательные параметры и только после этого включайте интеграцию.

Пример: `filter`, `normalize` и `store` образуют последовательный процесс импорта.

## Для чего нужен этот раздел
Интеграции передают данные между WMS и внешними системами. Сервисы хранят подключение, вебхуки принимают события, а правила обрабатывают их последовательно.
## Важные данные
Проверяйте **сервис**, тип события, порядок правил, JSON и статус. Секретные ключи не публикуйте в примерах.
## Пошаговая проверка
1. Используйте тестовый набор.
2. Проверьте каждый шаг цепочки.
3. Изучите журнал результата.
4. Только после проверки включайте регулярную синхронизацию.
