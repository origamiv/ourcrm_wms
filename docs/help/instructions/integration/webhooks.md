# Вебхуки

![Экран раздела Интеграции](/help-assets/integration.png)

Откройте **Интеграции → Вебхуки**, выберите сервис и тип хука, добавьте последовательные правила и сохраните. В таблице проверьте статус и действия. Сохранение настройки не отправляет данные автоматически.

Пример: вебхук маркетплейса получает товар, правило стандартизирует поля, следующее правило записывает результат в каталог.
