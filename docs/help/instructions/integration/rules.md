# Правила интеграций

![Экран раздела Интеграции](/help-assets/integration.png)

Правило выполняет один шаг обработки. В **Справочники → Правила** выберите тип обработки, задайте параметры JSON и сохраните. Порядок правил важен: фильтрация должна идти до записи, стандартизация — до сопоставления.

Пример цепочки: фильтр активных товаров → стандартизация названия → запись в каталог МП.
