# Импорты

![Экран раздела Обслуживание](/help-assets/maintenance.png)

Откройте **Обслуживание → Импорты**, чтобы контролировать запуски через очереди. Полная строка показывает проект, этап, число этапов, записи, чанки, обработанное количество и статус. Дочерние строки соответствуют отдельным этапам.

Пример: при ошибке этапа проверьте сообщение, `failed_jobs` и повторный запуск. Активные импорты обновляются автоматически; прогресс полного запуска считается по завершённым этапам.

## Для чего нужен этот раздел
Обслуживание показывает фоновые операции WMS и состояние очередей. Здесь можно определить текущий этап импорта и причину ошибки.
## Важные данные
Смотрите **статус**, текущий этап, число записей, чанков и текст ошибки. Повторный запуск не должен создавать дубли.
## Пошаговая проверка
1. Найдите запуск по времени.
2. Проверьте родительскую и дочерние строки.
3. При ошибке изучите failed_jobs.
4. Дождитесь завершения всех этапов.
