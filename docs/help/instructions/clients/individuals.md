# Физические лица клиентов

![Экран раздела Клиенты](/help-assets/clients.png)

Откройте **Клиенты → Физ.лица**, нажмите **Добавить запись**, укажите ФИО и контактные данные, проверьте клиента и сохраните. Для изменения откройте карандаш, для удаления подтвердите операцию.

Пример: используйте полное ФИО в карточке, а короткое имя — для поиска и таблиц.
