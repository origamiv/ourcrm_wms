# Юридические лица клиентов

![Экран раздела Клиенты](/help-assets/clients.png)

В **Клиенты → Юр.лица** добавьте организацию клиента, выберите её из подсказки по ИНН/ОГРН, проверьте реквизиты и сохраните. Используйте фильтр и колонку **Действия** для дальнейшей работы.

Пример: одна компания может иметь несколько контактных лиц и документов; перед удалением проверьте связанные записи.
