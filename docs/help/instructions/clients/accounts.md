# Доступы клиентов

![Экран раздела Клиенты](/help-assets/clients.png)

Откройте **Клиенты → Доступы**, выберите клиента, добавьте учётную запись и назначьте доступные права. Сохраните изменения и проверьте статус. Доступ ограничивается текущей организацией и назначенными ролями.

Пример: для бухгалтера оставьте только документы и просмотр, для оператора добавьте рабочие процессы.
