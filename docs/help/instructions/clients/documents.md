# Документы клиентов

![Экран раздела Клиенты](/help-assets/clients.png)

В **Клиенты → Документы** выберите клиента и тип документа, заполните номер, даты и сумму, добавьте позиции при необходимости и сохраните. Кнопка **Скачать PDF** формирует печатную форму.

Пример: даты вводите как `16.09.26`, ставку НДС `none` используйте для документа без НДС. При ошибке проверьте обязательные поля и реквизиты сторон.
