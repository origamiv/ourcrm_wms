# Клиенты

![Экран раздела Клиенты](/help-assets/clients.png)

Откройте **Клиенты → Клиенты**, выполните поиск по названию или краткому имени и выберите статус. Нажмите **Добавить запись**, заполните карточку и сохраните. В колонке **Действия** доступны просмотр, редактирование и удаление с подтверждением.

Пример: создайте клиента, затем откройте его документы и доступы через соответствующие пункты ленты. Удалённые записи ищутся фильтром «Удалённые».

## Для чего нужен этот раздел
Здесь хранятся клиенты, организации, контакты, документы и доступы. Эти данные используются рабочими процессами и должны оставаться непротиворечивыми.
## Важные данные
Проверяйте **организацию**, **статус**, идентификатор и связи. Не создавайте дубликат до поиска по названию, ИНН и краткому имени.
## Пошаговая проверка
1. Найдите существующую запись.
2. Заполните только подтверждённые данные.
3. Сохраните и проверьте связанные сущности.
4. Перед удалением устраните зависимости.
