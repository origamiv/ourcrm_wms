# Файлы

![Экран раздела Администрирование](/help-assets/main.png)

Откройте **Справочники → Файлы**, найдите запись по пути или расширению и проверьте метаданные. Справочник описывает зарегистрированный файл; содержимое файла загружается специализированным экраном, если он предусмотрен.

Пример: перед удалением проверьте, что путь не используется инструкцией или документом. После изменения метаданных обновите список.
