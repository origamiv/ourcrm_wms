# Пользователи

![Экран раздела Администрирование](/help-assets/main.png)

## Назначение
В разделе управляются учётные записи WMS и их статусы.

## Пошагово
1. Откройте **Администрирование → Пользователи**.
2. Нажмите **Добавить запись**, заполните имя, email и пароль.
3. Назначьте активную роль и сохраните карточку.
4. Для изменения откройте карандаш в колонке **Действия**; для удаления используйте корзину и подтвердите операцию.

Пример: создайте пользователя `оператор склада`, назначьте роль оператора и проверьте вход в новой вкладке. Статус «Новый» требует активации администратором.

## Результат и ошибки
Пользователь появляется в таблице. При конфликте email обновите данные и повторите сохранение; отключённый пользователь войти не сможет.
