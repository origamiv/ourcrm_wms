# Модули

![Экран раздела Администрирование](/help-assets/main.png)

В **Администрирование → Справочники → Модули** найдите модуль по названию или краткому имени. Нажмите **Добавить запись**, заполните название и код, установите статус и сохраните. Просмотр, редактирование и удаление выполняются из колонки **Действия**.

Пример: модуль `warehouse` используйте как родитель для возможностей склада. Используемый модуль нельзя удалять до переноса связанных возможностей.

## Важные данные
Раздел управляет настройками и справочниками WMS. Перед сохранением проверяйте **статус**, **краткое имя** и связанные записи.
## Контрольный список
1. Найдите запись через поиск.
2. Проверьте поля и зависимости.
3. Сохраните и откройте запись повторно.
