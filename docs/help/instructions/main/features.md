# Возможности

Откройте **Справочники → Возможности**, выберите модуль, укажите название и короткое имя, затем сохраните. В строке проверьте код и статус. Возможности используются при настройке прав ролей.

![Экран раздела Администрирование](/help-assets/main.png)

Пример: `goods.view` разрешает просмотр товаров, а `goods.edit` — изменение. После добавления назначьте возможность роли в пункте «Роли и права».

## Важные данные
Раздел управляет настройками и справочниками WMS. Перед сохранением проверяйте **статус**, **краткое имя** и связанные записи.
## Контрольный список
1. Найдите запись через поиск.
2. Проверьте поля и зависимости.
3. Сохраните и откройте запись повторно.
