# Роли

Роли объединяют права доступа. Откройте **Администрирование → Роли**, нажмите **Добавить запись**, укажите название и краткое имя, выберите статус и сохраните. Для изменения используйте название или карандаш, для удаления — корзину с подтверждением.

![Экран раздела Администрирование](/help-assets/main.png)

Пример: роль «Кладовщик» получает права на приемки, задачи и размещения, но не получает права администрирования. После изменения роли попросите пользователя заново войти. Системную роль `admin` не отключайте без проверки резервного администратора.

## Важные данные

Главные поля роли — **название**, уникальное **краткое имя**, статус и набор прав. Права назначаются отдельно в матрице «Роли и права»; создание роли само по себе не даёт ей доступа.

## Контрольный список

1. Убедитесь, что роль решает одну понятную задачу.
2. Выдайте минимально необходимый набор прав.
3. Проверьте роль тестовым пользователем.
4. Зафиксируйте изменения в журнале организации.
