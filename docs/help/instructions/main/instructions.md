# Инструкции

Откройте **Администрирование → Инструкции**. Слева находится таблица с колонкой **Действия**, справа — форма создания и редактирования. Укажите название, краткое имя, раздел и порядок, перетащите Markdown/PDF/HTML/MP4 в дропзону и нажмите **Добавить**. Для изменения выберите **Изменить** в строке.

![Экран раздела Администрирование](/help-assets/main.png)

Пример: инструкция с разделом «Товары» появится в `/goods/help`. Повторная загрузка файла заменяет содержимое, а статус определяет видимость для пользователей.

## Важные данные
Раздел управляет настройками и справочниками WMS. Перед сохранением проверяйте **статус**, **краткое имя** и связанные записи.
## Контрольный список
1. Найдите запись через поиск.
2. Проверьте поля и зависимости.
3. Сохраните и откройте запись повторно.
