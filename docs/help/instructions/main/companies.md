# Компании

![Экран раздела Администрирование](/help-assets/main.png)

1. Откройте **Администрирование → Компании** и нажмите **Добавить запись**.
2. Введите название, ИНН или ОГРН и выберите подсказку DaData, если она доступна.
3. Проверьте реквизиты, признаки «Наша», «Клиент», «Партнёр» и сохраните.

Пример: для своей организации отметьте «Наша», затем добавьте контактное лицо. Данные общей организации изменяются только администратором. Перед удалением проверьте связанные контакты.

## Важные данные

Компания — источник реквизитов для документов и связей с контактными лицами. Проверяйте **ИНН**, **ОГРН**, юридический адрес, банковские реквизиты и признаки организации перед сохранением.

## Пошаговая проверка

1. Сначала выполните поиск по названию, ИНН и ОГРН.
2. Выберите подсказку DaData или заполните реквизиты вручную.
3. Проверьте признак организации и сохраните карточку.
4. Откройте список контактов и убедитесь, что связь работает.
