# Поиск в таблицах

Нажмите значок лупы перед значком фильтра. Введите не менее трёх символов — поиск начнётся автоматически.

Кнопка-шестерёнка внутри поля открывает выбор колонок. Отметьте поля, в которых нужно искать; хотя бы одно поле всегда должно оставаться выбранным. Для каждого экрана выбор запоминается отдельно.

Кнопка режима переключает два варианта:

- Воронка оставляет в таблице только найденные строки.
- Документ с выделенной строкой сохраняет все строки и подсвечивает совпадения. Стрелки, `Enter` и `Shift+Enter` переходят между ними.

Чтобы свернуть пустой поиск, нажмите `Escape` или переведите фокус за пределы блока поиска.
