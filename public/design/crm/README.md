# Источник ассетов

Иконки и знак экспортированы без изменения байтов из [Figma: Администрирование — Пользователи, 9:33020](https://www.figma.com/design/x2UByywVb3CQd8dbC9MKEi/?node-id=9-33020).

`logo.png` — знак; `workspace.svg` — рабочий стол; `administration.svg` — администрирование; `contacts.svg` — пользователи; `profile.svg` — профиль; `logout.svg` — выход; `view.svg`, `edit.svg`, `delete.svg` — действия; `arrow_left.svg`, `arrow_right.svg` — пагинация.

Используются локальные файлы: временные URL Figma в интерфейсе не нужны. Шрифт Manrope поставляется пакетом `@fontsource/manrope`.

Ленточное меню соответствует узлу `9:33169`: `roles.svg` — экспорт значка контактных лиц, `permissions.svg` — экспорт значка сетки. Секции соединены общей рамкой, иконка расположена над подписью.

`roles_rights.svg` — точный экспорт иконки «Роли и права» из [узла 5667:664](https://www.figma.com/design/x2UByywVb3CQd8dbC9MKEi/?node-id=5667-664).

`key.svg` — локальная контурная иконка установки пароля, добавленная в размере и зелёном цвете остальных действий.

`close.svg` — точный экспорт крестика окна подтверждения из [узла 63:26876](https://www.figma.com/design/x2UByywVb3CQd8dbC9MKEi/?node-id=63-26876). Компонент `ConfirmDelete.vue` воспроизводит белое окно, зелёную рамку, кнопки и затемнение из этого макета.

`companies.svg`, `company_contacts.svg` — экспорт иконок компаний и контактных лиц; `tick.svg` — отметка признака компании. Список компаний основан на [5549:5551](https://www.figma.com/design/x2UByywVb3CQd8dbC9MKEi/?node-id=5549-5551), карточка справа — на [5457:192](https://www.figma.com/design/x2UByywVb3CQd8dbC9MKEi/?node-id=5457-192).
