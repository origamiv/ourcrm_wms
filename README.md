# WMS

Система управления складом на Laravel 12. Сейчас подготовлены правила разработки; техническая адаптация унаследованного приложения выполняется следующими этапами.

Целевая основа: стандартные каталоги Laravel внутри `app`, одна БД PostgreSQL со схемами функциональных модулей, изоляция организаций через `tenant_id`, ClickHouse для истории и статистики, Scramble для API. Новые доменные классы в `Modules` не размещаются.

В репозитории сохранён прежний способ запуска; его адаптация к целевой основе WMS ещё не выполнена. Перед использованием проверить скрипт и настройки окружения.
